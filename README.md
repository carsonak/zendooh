# Zendooh

An offline-first personal finance project built with Kotlin Multiplatform and Compose
Multiplatform. Android and desktop currently share a placeholder screen; financial
features are not implemented yet.

## Run locally

Install [mise](https://mise.jdx.dev/getting-started.html), then run:

```sh
mise trust
mise install
mise run run:desktop
```

Android SDK configuration is required by the build. See [CONTRIBUTING.md](CONTRIBUTING.md)
for environment setup, Android execution, tests, and quality checks.
